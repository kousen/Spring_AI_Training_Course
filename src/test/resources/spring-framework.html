Spring Framework

Spring Framework provides dependency injection, web application support, data access integration, and production-friendly configuration patterns for Java applications.

Spring Boot builds on the framework with auto-configuration, starter dependencies, Actuator endpoints, and conventions that simplify local development and deployment.

Spring AI follows the same programming model for AI applications. It includes chat clients, prompt templates, structured output, advisors, vector stores, document readers, and model provider integrations.

Retrieval-augmented generation combines document loading, chunking, embeddings, vector search, and prompt augmentation so a model can answer questions using application-specific context.
