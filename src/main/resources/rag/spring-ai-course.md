# Spring AI Course Version Notes

This course uses Spring Boot 3.5.14 with Spring AI 1.1.7. The labs stay on the
stable Spring AI 1.1.x line because it is compatible with Spring Boot 3.5.x and
keeps the classroom code aligned with released APIs.

Spring AI 2.0 milestone and release-candidate builds are preview material for
this delivery. They are useful to discuss when previewing Spring Boot 4.0,
Spring Framework 7.0, Jackson 3, and newer MCP transport changes, but the
hands-on labs should not depend on those preview APIs.

The core teaching path is ChatClient, advisors, structured output, prompt
templates, chat memory, tools, and retrieval-augmented generation. Multimodal,
Redis, and MCP labs are optional extensions.
