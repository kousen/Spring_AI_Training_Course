# Kendrick Lamar And Drake Feud Course Summary

The Kendrick Lamar and Drake feud became one of the most visible rap conflicts
of 2024. Many commentators viewed Kendrick Lamar as having the stronger
cultural momentum after the exchange, especially because "Not Like Us" became a
widely discussed and commercially successful record.

This file is not intended to be a complete music-history source. It exists as a
small, local RAG document for testing whether the application can retrieve
domain-specific context from the vector store.
